# Expense Tracker — Frontend

Flutter app (iOS + Android) for the Expense Tracker.

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the folder structure
and state management approach, and [`docs/DESIGN_SYSTEM.md`](docs/DESIGN_SYSTEM.md)
for color/typography/spacing/motion tokens — read that before building any
UI. The root `../CLAUDE.md` and `../STATUS.md` (one level up) have the
cross-project picture and current progress.

## Data modes

The same app runs against the backend (`cloud`, default) or fully offline on-device
SQLite (`local`): `./run_dev.sh local`. See [docs/DATA_MODES.md](docs/DATA_MODES.md).

## Setup

```bash
flutter pub get
flutter run
```

Requires a running instance of the backend (see `../backend/README.md`) and
the API base URL configured in `lib/core/network/api_client.dart` (once
scaffolded).

## Platforms

- `android/`, `ios/` — native project shells, generated by `flutter create`.
- Also has `linux/`, `macos/`, `windows/`, `web/` scaffolding from the default
  template — this app targets iOS + Android only; those extra platform
  folders are unused and can be ignored (not deleted, in case that breaks the
  Flutter tooling's expectations — worth revisiting once the app is further along).
